析间 Windows 本地桌面版 0.3.0-alpha.5

启动：完整解压后双击 Xijian\Xijian.exe。请保留整个 Xijian 文件夹。
Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime；不需要另装 Python。

新数据与记录位于 %LOCALAPPDATA%\Xijian\desktop-v1。
升级替换程序目录，保留上述用户数据目录。不会搬迁旧网页版工作区。
关闭桌面窗口会停止本窗口启动的后台服务，任务和历史记录保留。
已有窗口打开同一工作区时，请使用已有窗口。

在连接设置中配置内部模型 API，或创建企业 Agent 的 MCP 连接。
MCP 输入需要单独授权，公开包仍需在界面中批准。MCP 模式由宿主发起与接续；窗口不会自动唤醒任意 Agent。
Qoder 使用本机另外安装并登录的官方 Qoder CN CLI 与受支持桌面 SDK；本包不包含其程序或凭据。
本 Alpha 已核对的 Qoder 桌面为 0.2.3 / SDK 1.0.37。其他运行时需要重新核对，不能静默绕过版本准入。
API 凭据只留服务内存；重开后重新配置。MCP 授权由 Windows DPAPI 保护，可从界面撤销。

当前仅限合成数据试用。程序执行与模型解释均不表示数值已获独立认证。
账本的保守扣账、实际观测与供应商额度不同。不要通过新建工作区绕过同一使用授权的累计上限。
当前版本不是生产安全隔离，不接收生产数据。

此本地 Alpha 未签名、未发布到远端，尚未完成干净电脑和用户体验验收。
若启动失败，检查用户数据目录下的 desktop-host.log。不要删除历史结果后反复执行未知任务。

# 连接 Agent 运行节点

析间可以把批准的公共包送到另一台 Windows 机器，由该机器已配置的
Codex、OpenCode 或 Claude Code 生成程序，再取回原始 UTF-8 字节执行。
运行节点复用本机 Agent 适配器，不接收客户端指定的命令、路径或模型覆盖。

## 启动节点

先在节点机器的析间源码版中完成外侧 Agent 检测、检查与启用，使用该实例的
`external-agents` 设置目录和原 `token-budget` 目录。继续使用原账本；已有
消耗、调用上限和独立登录目录均保留。当前节点沿用 Windows 原生适配器和
文件锁；Python/pandas 环境要求与源码版一致。

在节点的产品源码目录执行（把三个路径替换为实际目录）：

```powershell
# 连接令牌由管理员生成并通过安全渠道提供给客户端；不要放在命令行参数中。
$env:XIJIAN_NODE_TOKEN = Read-Host '输入至少 32 字符的随机节点连接令牌'
python -B -m tools.workbench_remote --state C:/Xijian/node-state --agent-state C:/Xijian/workbench-state/external-agents --budget-root C:/Xijian/workbench-state/token-budget --port 8766
```

启动输出包含节点 ID、Agent、模型、身份摘要及状态，不包含令牌。节点仅监听
`127.0.0.1`。跨机连接可通过管理员维护的 SSH 本地端口转发：

```text
ssh -N -L 8766:127.0.0.1:8766 node-host
```

本轮已验证本机双进程通信；指定远程主机、SSH 隧道和真实账户运行尚待接续。

## 在析间连接

1. 打开连接设置 → **远程 Agent 运行节点**。
2. 填写 `http://127.0.0.1:8766`（隧道本地地址）与节点连接令牌。
3. 点 **连接运行节点**，查看 Agent、模型和节点 ID。
4. 创建新任务、检查并批准公共包。原数据与内部任务仍留在客户端。
5. 生成后沿用原程序检查、内部执行及换数据复用流程。

令牌只保留在服务进程内存中，输入框提交即清空。服务重启后重新连接；原任务
回执保留。客户端仅接受 HTTPS 或明确的回环 HTTP，拒绝跳转及系统代理。

## 进度、取消与恢复

- 每次提交前保存节点任务编号；界面显示编号，可以查询原任务状态。
- 相同编号和公共包重复到达只返回已有状态，不重复生成；不同包复用编号会被拒绝。
- 取消沿用任务取消入口，节点转为 `cancelling`，适配器结束后记为 `cancelled`。
- 客户端断线/超时保留 `unresolved` 回执，可查询节点的最终状态；不会再次 POST。
- 节点重启把未结束任务记为 `unresolved`，保留记录并阻止原编号重放。
- 下载必须同时匹配任务、节点、运行时和程序摘要；CRLF 与其他原字节不会重写。

首次生成和公开修复都使用单次投递。公开样例确定失败后，修复版本包含原公共包、
上一程序和公开失败代码。检查并单独批准该版本后才会发送。旧节点可以继续处理
首次生成，公开修复需要节点报告支持。

连接中断后，按原设置重新连接同一节点，在协作历史中打开原任务，点击
**从原节点取回程序**。节点显示生成完成且任务编号、节点身份、运行时、批准包和
程序摘要全部匹配时，程序会保存在原任务。之后由你选择继续公开检查和内部处理。
节点未就绪或余额不足时，仍可连接和取回已完成的程序。取消的任务保持停止。

运行节点设置中的状态查询不会
改变内部任务终态。额度在节点和客户端各自的账本中保守计入，各账本
分别控制自己的调用范围，不能相加作为供应商账单。

## 接口和本地验收

所有接口要求 `Authorization: Bearer <节点令牌>`：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/v1/capabilities` | 节点身份、Agent/模型、准入额度、就绪状态 |
| POST | `/v1/tasks` | 公共包、摘要、任务 ID、节点和运行时身份 |
| GET | `/v1/tasks/{id}` | 查询进度和终态 |
| POST | `/v1/tasks/{id}/cancel` | 请求取消 |
| GET | `/v1/tasks/{id}/candidate` | Base64 原字节与 SHA-256 |

源码验收命令：

```text
python -B -m pytest -q -p no:cacheprovider tests/test_workbench_remote.py --basetemp=dist/remote-node-test
node tests/test_workbench_remote_gui.cjs
```

验收使用合成 Agent 和回环服务，包括独立节点进程、内部执行 130、同程序复用
20、重复/篡改/取消/断线/重启/硬超时拒绝路径，并覆盖公开修复单独批准与
掉线后取回原程序。实际异机连接仍需用指定 Windows 节点核验。
